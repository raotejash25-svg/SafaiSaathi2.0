💡 Viva Defense & Technical Architecture Q&A

Q1: Why use smartphone browser GPS instead of dedicated IoT GPS hardware on the truck?

Defense: Standard municipal fleet IoT devices cost ₹3,000–₹5,000 per vehicle plus recurring 4G SIM maintenance and wiring vulnerabilities. SafaiSaathi leverages the HTML5 Geolocation Web API on the sanitation driver's existing smartphone with zero app store installation friction. This lowers the capital barrier for tier-2/3 Urban Local Bodies to absolute zero.

Q2: How does the system prevent false "Stop Completed" claims by drivers?

Defense: The backend geo-engine uses Haversine-based proximity & dwell verification. A checkpoint is only auto-verified when the driver's coordinates stay within a 75-meter geofence radius for at least 20 seconds. If a resident reports a miss, the admin desk cross-references the GPS breadcrumb log against the timestamp.

Q3: How is dynamic ETA computed without paying for expensive Google Maps Distance Matrix APIs?

Defense: We compute spherical distance using the Haversine formula combined with a calibrated urban residential detour coefficient (1.25x) and historical average collection speeds (~14 km/h). This produces a transparent, explainable ETA range with 0 API billing overhead.

Q4: How does this project scale beyond one ward in future iterations?

Defense: The architecture supports multi-tenant ULB ward partitioning, WebSockets for ultra-high concurrency, and SMS-based automated alerts for non-smartphone households.
